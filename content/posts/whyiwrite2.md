When I started this blog I said that I want to do it mostly [for myself]({{< relref "whyiwrite.md" >}}). Andy Hawthorne says something similar, [Why Blog If Nobody Reads It?](https://andysblog.uk/why-blog-if-nobody-reads-it). 

"Like blogging. You write because you think, because you observe, because you need to put it somewhere.
If someone reads it? Bonus. If not? The work still got done."

And after reading [Build a link blog](https://xuanwo.io/links/2025/01/link-blog/) I want to add that I could use the blog as a way to remember good links and what I was thinking when reading them.
