Why I write 2

16 Feb 2025

When I started this blog I said that I want to do it mostly for myself. Andy Hawthorne says something similar, Why Blog If Nobody Reads It?.

“Like blogging. You write because you think, because you observe, because you need to put it somewhere. If someone reads it? Bonus. If not? The work still got done.”

And after reading Build a link blog I want to add that I could use the blog as a way to remember good links and what I was thinking when reading them.
